## 4. Anti-Cannibalization Rules

1. **Title Uniqueness:** No two pages may share the same primary keyword in their `<title>` tag.
2. **Anchor Text Discipline:** Internal links pointing to a specific page must consistently use its assigned primary keyword as the anchor text (e.g., links pointing to `/features/excel-csv-ai-analysis` use "analyze Excel files with AI" or "Excel & CSV analyzer", never generic "click here").
3. **Canonical Enforcement:** Every page must specify its own self-referential canonical tag using `https://aidataanalystpro.co.uk/` with no trailing-slash inconsistencies.
4. **No Index on App Space:** All authenticated routes (`/dashboard`, `/upload`, `/chat`, `/admin/`, `/auth/`, `/api/`) remain strictly `noindex, nofollow` and disallowed in `robots.txt`.
