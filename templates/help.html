Q: What dataset file formats are supported?

AI Data Analyst Pro supports 9 enterprise file formats up to 100MB per file:

  • CSV (.csv) & TSV (.tsv) (Comma / Tab delimited)
  • Excel (.xlsx, .xls) (Multi-sheet workbooks)
  • JSON (.json) & XML (.xml) (Nested objects & arrays)
  • Parquet (.parquet) & Feather (.feather) (High-speed columnar binary datasets)
  • Text (.txt) (Delimited text files)

Q: How does the AI Voice Agent work?

Click the "Click to Speak (Voice AI)" pill button on the Ask AI page. The Web Speech API transcribes your speech in real-time, auto-corrects speech typos (e.g. "top 5 ross" ➔ "top 5 rows" or Urdu numbers "paanch" ➔ "5"), and executes the T-SQL query in sub-second time (0.02s) without reloading the page.

Q: Why does AI refuse casual/general knowledge questions?

The platform enforces a strict AI Context Guardrail. Non-dataset queries (e.g., "who is president", "tell me a joke", "weather today", or casual greetings like "hello") are caught in 0.001s without querying the database, returning:
"I can only answer questions related to uploaded datasets."

Q: What happens when I delete a dataset from the Dashboard?

Clicking Delete Dataset completely purges the dataset. It executes a DROP TABLE [{table_name}] command in SQL Server, cleans up associated query logs, and deletes the metadata row from the Datasets table.

Q: How do I export datasets and reports?

You can export data in 6 formats from the Dashboard or Query Results page: Excel (.xlsx) (styled workbook + summary KPI tab), PDF Report (executive layout + AI insights + chart), Word (.docx), PowerPoint (.pptx), Vector SVG (.svg), and CSV (.csv).
