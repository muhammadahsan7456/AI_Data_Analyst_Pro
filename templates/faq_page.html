Frequently Asked Questions

Find instant answers about security, features, pricing, and technical capabilities.

How does AI Data Analyst Pro secure dataset files?
All string and sensitive text columns are encrypted at rest using AES-256 Fernet Encryption before storage in SQL Server tables. Row-level user isolation guarantees that dataset records can only be queried by their owner. Sessions automatically expire after 1 hour of inactivity. Comprehensive audit logs track all activities for compliance.
What dataset file formats are supported?
AI Data Analyst Pro supports 9 enterprise file formats up to 500MB per upload:
  • CSV (.csv) & TSV (.tsv) — Auto-detected delimiters
  • Excel (.xlsx, .xls) — Multi-sheet workbooks
  • JSON (.json) & XML (.xml) — Nested objects flattened automatically
  • Parquet (.parquet) & Feather (.feather) — High-speed columnar binary
  • Text (.txt) — Fixed-width & delimited text files
How does the AI Voice Agent work?
Click the "Click to Speak (Voice AI)" button on the Ask AI page. The Web Speech API transcribes your speech in real-time, auto-corrects speech typos (e.g., "top 5 ross" → "top 5 rows" or Urdu numbers "paanch" → "5"), and executes the T-SQL query in sub-second time (0.02s) without reloading the page. Both English and Roman Urdu are fully supported.
Why does AI refuse casual/general knowledge questions?
The platform enforces a strict AI Context Guardrail. Non-dataset queries (e.g., "who is president", "tell me a joke", "weather today") are caught in 0.001s without querying the database, returning: "I can only answer questions related to uploaded datasets." This ensures enterprise data focus and prevents data exfiltration.
How do I export datasets and reports?
Export data in 6 formats from the Dashboard or Query Results: Excel (.xlsx) with styled sheets + summary KPI tab, PDF Report with AI insights + chart, Word (.docx), PowerPoint (.pptx) with executive slides, Vector SVG (.svg), and CSV (.csv). All exports generate in under 100 milliseconds.
What happens when I delete a dataset?
Clicking Delete Dataset permanently purges all data. It executes a DROP TABLE command in SQL Server, cleans up associated query logs, and deletes the metadata row. This action is irreversible and ensures complete data removal from the platform.
