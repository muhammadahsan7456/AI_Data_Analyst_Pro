1. Multi-Format Dataset Uploader

Supports 9 Enterprise Formats • Up to 10M+ Records

The uploader automatically detects character encodings (UTF-8, Latin-1, CP1252), cleans header column names, and provisions an isolated physical table inside SQL Server with zero data contamination.

Supported Formats & Parsing Engine:
  • CSV (.csv) & TSV (.tsv) — Chunk-streamed with auto delimiter sniff
  • Excel (.xlsx, .xls) — Multi-sheet parsing via openpyxl
  • JSON (.json) & XML (.xml) — Hierarchical tree flattening
  • Parquet (.parquet) & Feather (.feather) — High-speed binary columnar storage
  • Text (.txt) — Fixed-width and custom-delimited files

2. Voice AI & Natural Language Querying

English & Roman Urdu Speech Normalization

Ask analytical questions using your voice or keyboard. The voice engine normalizes spoken typos (e.g., "top 5 ross" ➔ "top 5 rows" or Urdu phonetic phrases like "sab se zyada revenue" ➔ MAX(revenue)) and executes optimized T-SQL in sub-second time.

Query Syntax & Natural Language Examples:
  • "Show top 10 customers by total sales" ➔ Instant GROUP BY aggregation
  • "What is the average transaction amount in 2026?" ➔ Instant AVG with date filter
  • "Which product category has the lowest margin?" ➔ ORDER BY ASC with margin calculation
