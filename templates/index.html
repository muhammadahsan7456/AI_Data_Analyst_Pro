All string and sensitive text columns are encrypted at rest using AES-256 Fernet Encryption before storage in SQL Server tables. Row-level user isolation guarantees that dataset records can only be queried by their owner.

We support CSV, Excel (.xlsx, .xls), and TSV files up to 500 MB per file, scaling up to 10,000,000+ rows with streaming chunk insertion and dynamic memory type downcasting.
