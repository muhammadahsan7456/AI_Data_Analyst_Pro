Got Questions?

Frequently Asked Questions

How does AI Data Analyst Pro secure dataset files?
All string and sensitive text columns are encrypted at rest using AES-256 Fernet Encryption before storage in SQL Server tables. Authorized logged-in users decrypt results transparently upon execution.
What file formats and sizes are supported?
We support CSV, Excel (.xlsx, .xls), and TSV files up to 500 MB per file, scaling up to 10,000,000+ rows with streaming chunk insertion.
How does the 1-Hour Session Expiration work?
For maximum enterprise security, if a logged-in user is inactive for 60 minutes, their session automatically expires and redirects safely to the login page.
